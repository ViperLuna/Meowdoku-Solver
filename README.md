# 🐱 Meowdoku Solver

Solves Meowdoku boards: one cat per row, column and color, with no two cats touching (diagonals included).

- **Screenshot:** upload a fresh or half-done board and it reads the grid size and colors automatically, including cats you have already placed.
- **Manual:** pick a size and paint the regions yourself, or touch up a misread screenshot.
- **Hint:** reveal one cat at a time, or Solve to see them all. Misplaced cats get a red outline.

Plain HTML/JS, no build step. Open `index.html` or visit the GitHub Pages site.
