# 🐱 Meowdoku Solver

Solves Meowdoku boards: one cat per row, column and color, with no two cats touching (diagonals included).

- **Screenshot:** upload a fresh or half-done board and it reads the grid size and colors automatically, including cats and X's you have already placed.
- **Manual:** pick a size and paint the regions yourself, or touch up a misread screenshot.
- **Hint:** makes the next logical move (easiest first) and explains it: placing a cat or X-ing out squares. **Solve** just shows the answer.

Plain HTML/JS, no build step. Open `index.html` or visit the GitHub Pages site.
